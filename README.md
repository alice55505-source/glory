# 得榮少年點名系統

給服事者用的單頁網頁（`index.html`），手機可直接開啟，資料存在瀏覽器（localStorage）。

1. **各地規定**：八堂課、每月家訪、每月聚集（小排或主日，選填）、每月主日（第 3 年起規定，次數可設）、每年 8 小時生命成長園、每年 4 小時社區服務；可新增自訂規定。
2. **得少資料**：姓名、生日（自動算年齡）、學校、年級、申請時間（某年 5 月／11 月），自動算第幾年。
3. **點名**：每月（家訪／小排／主日）、每年（時數）、八堂課。
4. **統計**：每月達標名單，可「分享圖片」到群組或「複製文字」。

換裝置或交接：在「各地規定」頁用「匯出備份／匯入備份」。
