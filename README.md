# 得榮少年點名系統

給服事者用的 PWA 網頁，部署在 Cloudflare Workers。每個召會一個獨立空間，同召會的服事者即時同步同一份名單。

## 使用方式

- **登入**：開啟後點選自己的召會、輸入密碼。第一位服事者按「新增我的召會」，預設密碼 `0000`。登入一次後，下次打開不用再登入。
- **① 各地規定**：修改密碼、登出／切換召會、編輯與新增規定；生命成長園、社區服務可設定活動名稱與時數。
- **② 得少資料**：姓名、生日（自動算年齡）、學校、年級、申請時間（某年 5 月／11 月）。
- **③ 點名**：選名字（月曆點家訪／小排，週日多主日；下方直接顯示並可填寫該得少的年度時數與八堂課）、選聚會（選日期與聚會，勾出席名單）。每月次數由每日紀錄自動統計。
- **④ 統計**：每月達標名單，可「分享圖片」或「複製文字」到群組。

## 規則邏輯

- 第幾年、每年時數：依各人申請月起算（例：2025 年 11 月申請 → 第 1 年為 2025/11–2026/10）。
- 待申請（申請月還沒到）的得少也列入名單，只需完成八堂課。
- 每月聚集：前兩年小排或主日皆可；第 3 年起必須是主日（年數可在規定中修改）。
- 本月達標：看八堂課與每月的規定項目；每年項目顯示年度累計進度。

## 架構

- `public/`：前端（`index.html`、PWA manifest、service worker、圖標）
- `src/worker.js`：API 與 Durable Objects
  - `Registry`：召會清單
  - `ChurchRoom`：每個召會一個，存密碼（加鹽雜湊）、登入憑證、點名資料，WebSocket 即時廣播修改
- 離線時修改會先存在手機，連線後自動上傳。

## 開發與部署

```bash
npm install
npm run dev      # 本機 http://localhost:8787
npm run deploy   # 部署到 Cloudflare（需先 npx wrangler login）
```

或在 Cloudflare 後台：Workers & Pages → 建立 → 匯入 GitHub 存放庫，選這個 repo，部署指令 `npx wrangler deploy`。免費方案即可（Durable Objects 使用 SQLite 儲存）。
